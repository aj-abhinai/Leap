## What is Leap?

Leap is a self-hosted pipeline CRM for internal teams. It tracks contacts and leads, and it records every change in an audit log. The whole system runs as a single binary, with no separate asset directories.

[![The Leap dashboard with pipeline health and recent tasks](/screenshots/dashboard.png)](/screenshots/dashboard.png)

## Key Features

<CardGrid>
  <Card title="Dashboard" icon="laptop">
    The landing page shows contact and lead counts, pipeline health, upcoming reminders, and recent tasks.
  </Card>
  <Card title="Contacts" icon="building">
    One record per client, with multiple phones, emails, tags, statuses, and notes. Phones are stored in the international format. CSV import and export are included.
  </Card>
  <Card title="Pipeline Kanban" icon="list-format">
    Pipelines have custom stages with open, won, or lost outcomes. Leads move between stages on a kanban board. One open lead per contact, pipeline, and program prevents duplicates.
  </Card>
  <Card title="Activities and Reminders" icon="comment">
    Each lead has a timeline of tasks. Quick replies log an outcome and can auto-create the next task. Reminders prefill from the nudge lead time and surface overdue work.
  </Card>
  <Card title="Program Catalog" icon="document">
    Fixed-price programs are managed in Settings. Lead values are price snapshots at creation time, so later price changes do not affect existing leads.
  </Card>
  <Card title="Role-Based Access Control" icon="setting">
    Roles carry per-action permissions on contacts, leads, pipelines, users, and settings. Three protected roles ship with the app: superadmin, Sales, and Viewer. A superadmin account is created on first run.
  </Card>
  <Card title="Audit Log" icon="open-book">
    Every change is recorded with the user, the time, and a JSON diff. The activity feed shows the whole team what happened.
  </Card>
  <Card title="Secure Sessions" icon="lock">
    Short-lived access tokens, a refresh cookie, and CSRF protection keep sessions safe. Login and refresh are rate-limited.
  </Card>
  <Card title="Single Binary" icon="rocket">
    The Go backend contains the Vue frontend and the database migrations. Deploy with one `docker compose` command.
  </Card>
</CardGrid>

## Tech Stack

### Backend

- **Go 1.25+** with the chi router and pgx. Raw SQL, no ORM.
- **PostgreSQL 17** for data storage. golang-migrate runs the migrations at startup.
- **JWT** for authentication, with refresh cookies and CSRF protection.

### Frontend

- **Vue 3** with the Composition API and TypeScript.
- **Vite** for build tooling.
- **Tailwind CSS v4** and **shadcn-vue** for styling and UI components.
- **Pinia** and **TanStack Query** for state management.

### Deployment

- **Docker Compose** for one-command deployment.
- **stuffbin** packs the frontend and migrations into the binary.
